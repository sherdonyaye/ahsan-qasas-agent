# احسن القصص — صف رایگان استخراج گفتار

این پروژه یک ابزار آمادهٔ نصب است؛ هنوز به حساب شما نصب یا فعال نشده است.
هیچ API پولی ندارد. کتاب تولید نمی‌کند و ادعای تماشای تصاویر یا بررسی علمی روایت‌ها ندارد.

## کارهایی که انجام می‌دهد

- دریافت لینک ویدیو یا پلی‌لیست در دکمهٔ Run workflow؛ کشف تعداد واقعی قسمت‌های در دسترس، بدون فرض عدد ۹۴.
- دریافت عمومی صوت با yt-dlp و تبدیل کل گفتار فارسی با Whisper medium روی CPU.
- متن دارای زمان‌بندی، JSON، زیرنویس SRT و جمله‌های دارای اشاره به منابع.
- ذخیرهٔ پیشرفت پس از هر قسمت؛ اجرای بعدی قسمت‌های کامل را تکرار نمی‌کند.
- حداکثر دو قسمت و حدود ۱۸ دقیقه پردازش در هر نوبت؛ هر قسمت حداکثر ۱۵ دقیقه. پس از دو شکست، آن قسمت تا بررسی دستی متوقف می‌ماند.
- ارسال ZIP به تلگرام، در صورت تنظیم دو Secret اختیاری. این نسخه لینک ورودی را از تلگرام دریافت نمی‌کند.

## نصب ساده در GitHub

۱. یک مخزن جدید و مستقل با نام `ahsan-qasas-agent` بسازید. برای اجرای ابری این بسته، مخزن باید **Public** باشد. متن‌های خام و وضعیت صف در همان مخزن عمومی ذخیره می‌شوند؛ فایل خصوصی یا محتوای منتشرنشده در آن قرار ندهید. مخزن شعر را تغییر ندهید.

۲. ZIP را باز کنید. **محتویات** پوشه را در ریشهٔ مخزن قرار دهید. پوشهٔ `.github/workflows` نیز باید آپلود شود. اگر مرورگر پوشهٔ مخفی را نمی‌فرستد، فایل workflow را از گزینهٔ Add file > Create new file با مسیر `.github/workflows/qasas.yml` بسازید و متن فایل را در آن کپی کنید. بقیهٔ فایل‌ها را Upload files کنید.

۳. Settings > Actions > General > Workflow permissions را روی Read and write permissions بگذارید تا پیشرفت ذخیره شود. اگر سازمان شما این اجازه را نمی‌دهد، اجرا را شروع نکنید تا ذخیرهٔ پایدار تنظیم شود.

۴. به Actions بروید، `Ahsan Qasas free transcription` را انتخاب و Run workflow را بزنید. لینک مجموعه را وارد کنید:

https://www.youtube.com/playlist?list=PLswYkv98UynRbeZXA3GWEKA_U0An19weF

مدل medium پیش‌فرض است. نخست یک نوبت را بررسی کنید. سپس برای ادامهٔ خودکار در Settings > Secrets and variables > Actions > Variables متغیر `ENABLE_QASAS_AUTORUN` را با مقدار `true` بسازید. هر شش ساعت یک نوبت اجرا می‌شود؛ زمان‌بندی GitHub ممکن است تأخیر داشته باشد. برای توقف مقدار را false کنید. پس از پایان صف نیز false کنید تا اجرای بیهوده ادامه پیدا نکند.

۵. فایل خروجی در صفحهٔ هر اجرا، بخش Artifacts با نام `ahsan-qasas-review` است. گزارش `state/STATUS.md` نیز در مخزن است. ماندگاری آرتیفکت ۷ روز است؛ متن‌ها در تاریخچهٔ مخزن باقی می‌مانند.

## تلگرام اختیاری

در ربات رسمی https://t.me/BotFather با `/newbot` ربات بسازید و در چت ربات خودتان Start بزنید. توکن را در چت با دیگران نفرستید و داخل کد نگذارید.

در GitHub > Settings > Secrets and variables > Actions > Secrets دو مورد بسازید:

- `TELEGRAM_BOT_TOKEN`: توکن ربات
- `TELEGRAM_CHAT_ID`: شناسهٔ عددی چت خودتان

بدون این دو مورد، پردازش و خروجی GitHub همچنان کار می‌کند. ارسال خروجی فقط پس از پردازش یک قسمت تلاش می‌شود؛ خطای تلگرام نتایج را پاک نمی‌کند. دریافت لینک و فرمان از تلگرام در این نسخه پیاده نشده است.

## محدودیت‌های واقعی

- رایگان بودن یعنی استفاده از مدل متن‌باز و runner استاندارد مخزن عمومی؛ هیچ پرداخت یا runner پولی در این پروژه تنظیم نشده است. مصرف و محدودیت ذخیره‌سازی GitHub همچنان تابع حساب و سیاست روز آن است. فعال‌سازی هزینهٔ اضافی لازم نیست و توصیه نمی‌شود.
- روی مخزن خصوصی job عمداً اجرا نمی‌شود. سهمیهٔ آن ممکن است با پروژهٔ شعر مشترک باشد.
- یوتیوب ممکن است دریافت از سرور GitHub را مسدود کند؛ این برنامه آن محدودیت را دور نمی‌زند. موفقیت دانلود لپ‌تاپ تضمین موفقیت سرور نیست.
- CPU رایگان ممکن است برای یک قسمت با مدل medium ظرف ۱۵ دقیقه کافی نباشد. این به معنی امکان پردازش رایگان همهٔ ۹۴ قسمت نیست. در این صورت باید زمان/مدل یا محل اجرا بازبینی شود؛ small برای نمونهٔ فعلی شما خطاهای زیادی داشت.
- مدل در هر نوبت دوباره دانلود می‌شود؛ عمداً cache بزرگ و قابل‌هزینه تنظیم نشده است.
- ادامه از ابتدای قسمت ناقص است، نه از ثانیهٔ قطع‌شده. قسمت‌های کامل حفظ می‌شوند.
- اشتباه در فارسی دری، نام‌ها و عربی محتمل است. نبود پرچم خطا به معنی صحت نیست. آیات و احادیث باید با منابع اصلی و بازشنوی بررسی شوند.
- اشاره‌های منبع، خلاصهٔ تحلیلی یا تأیید اعتبار حدیث نیستند. پس از دریافت متن‌ها، مرحلهٔ بررسی با شما در ChatGPT انجام می‌شود. اتصال خودکار به این گفت‌وگو وجود ندارد.
- هیچ‌یک از نتایج آزمایش فعلی به معنی بررسی کامل مجموعه نیست. نوشتن کتاب تا بررسی منابع شروع نمی‌شود.

## عیب‌یابی

اگر دریافت یوتیوب خطا داد، schedule را خاموش و گزارش اجرا را بررسی کنید؛ ربات تلگرام این مانع را رفع نمی‌کند. برای تکرار قسمت خطادار پس از رفع مشکل، عدد مربوط به شناسهٔ آن در `state/attempts.json` را صفر کنید. متن‌های تکمیل‌شده را حذف نکنید. تغییر پلی‌لیست به یک مخزن جدا نیاز دارد.

## آزمایش انجام‌شده

تست‌های صف، خروجی، توقف، تکرارنشدن قسمت کامل و اعتبارسنجی لینک با دادهٔ ساختگی اجرا شده‌اند. در این محیط دانلود و تبدیل واقعی ویدیو روی GitHub و ارسال تلگرام آزمایش نشده‌اند. فعال‌سازی واقعی به مخزن جدید و در صورت نیاز Secretهای تلگرام وابسته است.
